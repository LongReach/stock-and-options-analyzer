# claude

While I've developed most of the code here by hand, I started using Claude Code in April 2026 and have been cautiously using it to add new features. "Cautiously" because this codebase is complex, and I've yet to develop perfect instincts for how much heavy lifting you can entrust a chatbot with.

For now, this folder contains instructions for various subprojects that Claude has assisted me with. It's in this repository mainly to show potential employers how I'm integrating AI tools into my working process. Because, as it seems from the brutal current job market, software developers who *AREN'T* doing that might be something analogous to horse cavalry charging a heavy machine gun emplacement in World War One. Well-trained and skilled, perhaps, but for the wrong century.
