# data

## Purpose

This folder is home to caches of stock data, going back decades, for various commonly-traded stocks and ETFs.

| File             | Purpose                                         |
|------------------|-------------------------------------------------|
| `market_data.h5` | OHLC trade data, daily and weekly.              |
| `iv_data.h5`     | OHLC implied volatility data, daily and weekly. |
